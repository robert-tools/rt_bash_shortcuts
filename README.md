# rt - robert.tools

## install

- install with git clone `git clone git@github.com:robert-tools/rt_bash_shortcuts.git`
- reference in .bashrc: `source ~/<folder>/rt_bash_shortcuts/.fn.bashrc`

## usage

easy installing of @robert.tools npm packages

```bash

rt status # get the status of all @robert.tools packages
rt outdated # check for outdated @robert.tools packages

rt curl
rt curl 1.0.4
rt curl latest
rt curl update

rt curl status # get the status of specific package

rt curl latest --save-dev
rt curl 1.0.4 --save-dev
```
